4. Running average

Watch the sample average change as more shuffles are included.

The purple line is the running mean; the dashed gold line is the theoretical expected value for a true random shuffle. The average can move up or down; it is not guaranteed to get closer at every step.

6. Compare the algorithms

The repeat-avoiding method excludes the previous artist whenever at least one other artist still has songs available.

Same playlist · Different selection rules

Every ordering of the individual songs is equally likely. Consecutive songs by the same artist can occur naturally.

Run a simulation to see the true-random average.

At each step, the algorithm chooses uniformly from the remaining songs whose artist differs from the previous song, if any such songs remain. If no alternatives remain, it chooses from all remaining songs.

Run a simulation to see the repeat-avoiding average.

Important: the two algorithms do not have the same probability distribution. The repeat-avoiding method is not a uniformly random permutation. Its average must be measured or derived for the specific playlist and rule.
